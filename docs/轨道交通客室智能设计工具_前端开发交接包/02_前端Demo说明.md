# 前端 UI Demo 说明

## 1. Demo 定位

`frontend-demo/rail-cabin-ai-prototype.html` 是单文件静态原型，用于确认页面范围、业务词汇、布局密度、操作入口和服务边界。当前 Demo 不包含真实登录、上传、API 请求、GPU 任务或数据持久化。

正式开发时应以架构说明中的模块边界重建工程，不建议继续在单个 HTML 文件中叠加生产逻辑。

## 2. 启动方式

直接使用浏览器打开：

```text
frontend-demo/rail-cabin-ai-prototype.html
```

所有必要图片均位于相对目录 `assets/`，交付包可离线打开。

## 3. 当前页面

1. 登录页：账号、密码和验证码示意。
2. 首页：产品定位、真实高铁主视觉和四项核心能力。
3. 客室效果生成：输入参数、画布、结果和任务队列。
4. CMF 生成器：面料、地板和墙板纹样生成。
5. 客室零部件生成器：多角度、参考图和局部修改。
6. 遮罩与分区标记：画笔、分区列表和局部修改提示词。
7. LoRA 素材库：CMF、零部件和客室风格模型管理。
8. LoRA 训练：底模、数据集、参数、专业设置和训练管理。
9. 2D 生 3D：三视图上传、输出格式和模型预览。
10. 自动报告：选择项目素材并生成 Word/PPT。
11. 资源库：图片、材质、模型和报告管理。
12. 用户与权限：管理员和普通用户能力对比。
13. AI 助手：设计边界、提示词、规范和摘要问答。

## 4. 页面与服务范围

| 页面区域 | 服务范围 | 后续接口 |
| --- | --- | --- |
| 客室效果、CMF、零部件 | ComfyUI 工作流服务 | `/api/v1/workflows`、`/api/v1/jobs` |
| LoRA 训练入口和训练页面 | AI Toolkit 训练服务 | `/api/v1/training-*` |
| AI 悬浮按钮和抽屉 | AI 助手服务 | `/api/v1/assistant` |
| 登录、用户、权限、通知 | 平台基础服务 | `/api/v1/auth`、`/users`、`/roles` |
| 项目、资源库、报告记录 | 项目资源服务 | `/api/v1/projects`、`/assets` |
| 2D 生 3D、报告生成 | 扩展任务适配器 | 统一 `/api/v1/jobs` |

## 5. 当前代码结构

```text
HTML
  顶部全局栏
  工作流 Tab
  13 个 screen 容器
  浮动捕捉窗口与 AI 抽屉

CSS
  品牌 Token
  三栏工作台
  表单与任务组件
  首页、训练页、弹窗和资源卡片

JavaScript
  静态 screenData
  模板字符串生成页面
  data-screen 页面切换
  弹窗、抽屉和模型选择交互
```

## 6. 设计系统

| Token | 色值 | 用途 |
| --- | --- | --- |
| 品牌主红 | `#c7001a` | 主按钮、Tab、进度和选中状态 |
| 品牌深红 | `#a90016` | 主按钮深色端和强调状态 |
| 品牌浅红 | `#fff0f2` | 选中背景和浅色标签 |
| 正文 | `#151922` | 标题和正文 |
| 辅助文字 | `#6b7280` | 描述和提示 |
| 边框 | `#e5e7eb` | 面板和分割线 |
| 页面背景 | `#f3f5f8` | 工作台背景 |
| 在线状态 | `#18a058` | 服务在线和完成状态 |

当前 CSS 变量仍使用早期名称 `--blue`、`--blue-2`、`--blue-3`，正式工程应改为 `--brand-primary`、`--brand-primary-dark`、`--brand-primary-soft`。

## 7. 正式开发迁移规则

- 将每个页面拆成独立路由和模块。
- 将三栏工作台抽象为通用布局组件。
- 将工作流参数面板改为 Schema 驱动表单。
- 将静态 `screenData` 替换为后端接口返回的配置和数据。
- 页面组件不允许出现 ComfyUI 节点 ID、AI Toolkit 文件路径或 DeepSeek Key。
- 文件上传统一返回 `assetId`。
- 所有任务复用统一状态、进度、错误、取消和重试组件。
- 权限由路由守卫和后端共同校验。
- AI 助手只保留一个全局入口，并能引用当前项目和画布资源。

## 8. 已知限制

- 登录按钮不校验账号和验证码。
- 上传框、屏幕捕捉和遮罩编辑仅表达交互概念。
- 任务进度、资源卡片和用户数据均为静态示例。
- 2D 生 3D 未接入真实模型预览。
- 报告未生成真实文件。
- Demo 使用桌面优先布局，尚未进行移动端适配。
- 当前没有 OpenAPI 类型、自动化测试和错误监控。
